# CYP FLAME 2026

The website for FLAME, the Chabad Young Professionals S. Pete Chanukah party.

Live at **https://flame.chabadyoungsp.com/**

- `index.html` is the whole page. The settings people usually change (event date,
  early-bird dates, ticket form, video, headline layout) are listed at the top of the file.
- `photos/` holds the slideshow and gallery photos.
- `CNAME` tells GitHub Pages to serve this site at flame.chabadyoungsp.com.
